# Demo video: full script

Open **https://krishna27-spec.github.io/rare-disease-atlas2/** in a new browser window, full screen, and start recording.

This is the complete walkthrough: every feature, in the order a visitor would meet them. Read at a calm pace it runs about four minutes (roughly 600 words).

**Important:** the submission guide caps the demo video at 60 seconds. This full version is too long for that slot. Use it as the longer team video or walkthrough, and for the 60-second demo read the short script in [`VIDEO_SCRIPTS.md`](VIDEO_SCRIPTS.md) (Video 1), which is the same story in six lines.

## What each thing on screen is, in one line

So you know what you are pointing at.

| On screen | What it is |
|---|---|
| The three boxes on Overview | Facts from Orphanet: how common, age it starts, how it is inherited |
| The map (Connections) | The disease in the middle, and everything the Atlas can link to it with evidence |
| Blue points | Genes |
| Light purple points | Biological mechanisms (pathways) |
| Larger purple points | Related diseases |
| Green points | Patient organisations |
| Pink points | Symptoms that a research paper states |
| Solid green line | From a trusted database |
| Dotted cyan line | Read from a paper or a patient group's website; the sentence is stored |
| Dashed amber line | Calculated by Atlas (similarity). A lead to check |
| The panel that slides in | The proof behind one line: source, date, strength, quoted sentence |
| "Second model agrees" | A second AI model re-read the quote and confirmed it supports the fact |
| The row of circles (Landscape) | Eight steps toward a treatment. Green tick means the Atlas found evidence for it |
| World map glows | Cities where studies run. Green and pulsing means recruiting now |
| Phase bars | How many treatment trials reached each stage (phase 1 is earliest, phase 3 is the last before approval) |
| "Ran to completion" | The trial finished as planned. It does not mean the treatment worked |
| Funding number | US public (NIH) research money found for this disease |
| 10× route | Reusing existing natural history studies instead of starting a new one |
| Natural history study | A study that records how a disease progresses without treatment. Regulators ask for one before trials |

## Before you record

- Do one silent run-through so you know where each tab and button is.
- If you make a mistake, pause two seconds and repeat the line; cut the mistake afterwards.
- The intro plays once per browser window. To see it again, open a new window.
